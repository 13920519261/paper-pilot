# PaperPilot 账号系统与 AI 模型通道（0.14.0 设计文档）

> 客户端（本插件）已实现并经 50 项 E2E 测试验证；配套账号后台（server/）与启动管理器已随仓库交付，
> 双击项目根目录 `启动PaperPilot后台.bat` 即可管理（见第四节）。
> 模型通道管理移植自「AI 带教中心」的通道面板，功能结构与交互逻辑保持一致。

## 一、总体架构

```
Zotero 插件（本文档）
├── Account（ai/account.js）      邮箱密码登录 / 会话持久化 / 过期处理 / 用量展示
├── Channels（ai/channels.js）    模型通道注册表 / 厂商预设与探测 / 官方通道权限
└── AIClient（ai/client.js）      全部 AI 功能统一从「活动通道」取配置调用

账号服务器（默认 http://127.0.0.1:8000，可在设置中修改）
├── /api/auth/*                   鉴权三端点（登录/登出/会话信息）
└── /v1/*                         OpenAI 兼容网关（models + chat/completions，Bearer 令牌）
```

核心规则：**登录后免费使用官方默认模型；未登录时官方通道不可切换、不可调用**（所有 34 项 AI 功能统一拦截并给出指引），用户仍可配置自己的通道使用任意 OpenAI 兼容接口。

## 二、服务端 API 契约

所有应答为 JSON；鉴权头 `Authorization: Bearer <token>`。

### 1. 登录

```
POST /api/auth/login
{ "email": "user@example.com", "password": "..." }

200 { "ok": true, "token": "pp-xxx", "expiresAt": "2026-10-09T00:00:00Z",
      "user": { "email": "user@example.com", "name": "昵称", "plan": "Free",
                "dailyUsed": 3, "dailyLimit": 100 } }
401 { "ok": false, "error": "邮箱或密码错误" }        # 文案由服务端定，客户端原样展示
429 { "ok": false, "error": "尝试过于频繁" }
```

- `expiresAt`：ISO 8601；客户端据此做本地过期判断
- `user.dailyUsed/dailyLimit`：官方模型每日用量展示（可缺省）

### 2. 登出

```
POST /api/auth/logout        # Bearer token
200 { "ok": true }
```

客户端尽力调用（2s 超时，失败不影响本地登出）。

### 3. 会话信息（刷新用量 / 滑动续期）

```
GET /api/auth/me             # Bearer token
200 { "ok": true, "user": { ... }, "expiresAt": "..." }   # 返回 expiresAt 即滑动续期
401 { "ok": false, "error": "登录已过期" }
```

调用时机：插件启动恢复会话时、设置面板「刷新状态」按钮。401 → 客户端自动失效会话。

### 4. 官方模型网关（OpenAI 兼容）

```
GET  /v1/models              # Bearer token → { "data": [{ "id": "auto" }, ...] }
POST /v1/chat/completions    # Bearer token → 标准 OpenAI 格式（支持 SSE 流式）
```

`model` 取值：`auto`（官方默认模型）或网关支持的具体模型名。401/403 → 客户端视为登录过期，自动失效会话并弹窗提醒。

### 5. 注册页

客户端「注册账号」链接打开 `{server}/register`（浏览器网页注册，不嵌入插件）。

## 三、客户端实现要点

### 会话与安全

- **持久化**：`{Zotero数据目录}/paperpilot-account.json`，`IOUtils.writeUTF8` + `tmpPath` 原子写 + `0o600`；不进 prefs（避免明文/被配置同步带走），**密码永不落盘**
- **过期处理**：本地 `expiresAt` 判断（启动时过期即静默清理）+ 服务端 401 双保险（AI 调用/刷新遇 401 → 清会话 + 弹窗「登录已过期」+ UI 联动切回未登录态）
- **网络异常翻译**：超时/拒连/5xx/429 均给出可操作中文提示（如「本地网关未启动，或地址在设置中改错」）
- **卸载清理**：`bootstrap.js` uninstall 时删除会话文件

### 模型通道（pref `aiChannels`）

```json
{ "channels": [ { "id": "deepseek-main", "name": "DeepSeek 日常", "provider": "deepseek",
    "baseUrl": "https://api.deepseek.com/v1", "apiKey": "sk-...",
    "model": "deepseek-chat", "models": ["deepseek-chat", "deepseek-reasoner"],
    "extraBody": {}, "timeoutMs": 12000 } ],
  "active": "official" }
```

- **官方通道**（`official`）：恒存在、置顶、不可删除；`baseUrl`/`apiKey` 由账号系统运行时注入（不落盘）；未登录不可设为活动通道；模型可在账号卡片切换（auto + 网关模型列表）
- **交互**（与原通道面板一致）：状态卡（活动通道/模型/总数）→ 通道行（切换/实测/参数/删除）→ 新增/编辑表单（厂商预设自动填充、🔍 检测按密钥格式圈定候选并行探 /models、📡 拉取上游模型、模型 chips、extraBody JSON、探活超时；编辑时 Key 留空=保持原密钥）
- **迁移**：首次启动把旧版 `aiBaseUrl/aiApiKey/aiModel` 与 `aiProfiles` 快照自动转为通道（幂等，不丢数据）；删除活动通道自动回落官方通道
- **快速切换**：工具菜单「PaperPilot AI 模型通道」+ 工作台顶栏下拉

### AIClient 消费链

`AIClient.chat/chatStream` 每次调用实时解析 `Channels.getActiveConfig()`：

| 状态 | 行为 |
|---|---|
| 官方通道 + 已登录 | 网关 = `{server}/v1`，令牌 = 登录 token |
| 官方通道 + 未登录 | 抛「官方模型需要登录：请在 设置 → PaperPilot 登录账号…」（34 项功能 catch 链直接展示） |
| 自定义通道 | 通道 baseUrl/apiKey/model/extraBody（extraBody 并入请求体） |
| 官方通道调用遇 401/403 | 自动失效会话 + 弹窗提醒 |

`hasKey()`（各功能的「AI 可用」门）在官方通道未登录时返回 false，提示文案统一为登录引导。

## 四、账号后台服务端（server/，0.14.0 已随仓库交付）

> Node ≥ 14 零依赖实现（`server/account-server.js`），完整实现第二节契约 + 本机管理 API。
> 端到端测试 71/71（`.workbuddy/account-tests/test-server.js`）。

### 架构

```
server/
├── account-server.js        主入口：鉴权 + 官方网关 + 管理 API（--port=8000，env PP_PORT/PP_DATA_DIR）
├── lib/presets.js           17 家厂商预设（与插件端 channels.js 同源维护）
├── lib/store.js             JSON 原子存储（tmp+rename，损坏自动备份回退）
├── public/admin.html        浏览器管理页（/admin，仅本机）
└── data/                    运行时数据（gitignore，绝不入库）
    ├── users.json           用户（scrypt 密码散列）+ 令牌表（仅存 SHA-256 散列）
    ├── channels.json        官方网关上游通道池 + active
    └── server-console.log   控制台日志（经启动管理器启动时）
```

### 与插件的关系

- 插件默认 `http://127.0.0.1:8000` **零改动直连**：登录 → 令牌 → `/v1` 网关
- 官方网关把登录用户请求转发到**服务端活动通道**上游（`auto` → 通道默认模型，`extraBody` 合并不覆盖调用方键，SSE 流式透传，上游 4xx/5xx 原状态码透传）
- 服务端通道池与**插件本地通道**（用户自己的 Key）互不相干：前者决定「官方模型走哪个上游」，后者是用户直连
- 每成功转发一次用量 +1；超 `dailyLimit` 返回 429；套餐有效期过期自动降级 Free 限额

### 管理 API（仅 127.0.0.1）

| 分组 | 端点 |
|---|---|
| 健康检查 | `GET /api/health` |
| 厂商预设 | `GET /api/admin/providers` |
| 用户 | `GET/POST /api/admin/users` · `PUT/DELETE /api/admin/users/:id` · `POST /api/admin/users/:id/password` |
| 通道 | `GET/POST /api/admin/channels` · `PUT/DELETE /api/admin/channels/:id` · `PUT /api/admin/channels/active` |
| 通道探测 | `POST /api/admin/channels/:id/test`（实测）· `GET /api/admin/channels/:id/models`（拉取）· `POST /api/admin/channels/detect`（密钥检测） |
| 管理页 | `GET /admin`（浏览器版通道+账号管理）· `GET /register` → 302 管理页 |

安全要点：密码 scrypt+盐（timingSafeEqual 校验）；令牌只存 SHA-256 散列（数据文件泄露拿不到可用令牌）；登录限速每 IP 每分钟 10 次；重置密码/删除用户即吊销其全部令牌；`/api/admin/*` 与 `/admin` 仅接受本机回环连接。

### 启动管理器（对标心血管药物学习平台）

```
启动PaperPilot后台.bat        # 根目录，双击无窗拉起 GUI（临时 vbs 桥）
scripts/launcher.ps1          # WinForms 控制台（PS 5.1 兼容，UTF-8 BOM）
scripts/start-server-hidden.vbs  # 后台无窗启动（开机自启经 HKCU Run 键）
```

控制台功能：

1. **账号后台控制**：启动/停止/重启/查看日志 + 状态灯（端口 8000 健康检测，running/starting/degraded/stopped 四态）
2. **AI 模型通道管理**（弹窗）：通道列表（● 活动标记/Key 掩码）、设为活动、实测（延迟+应答）、编辑（Key 留空保持原密钥）、删除（活动通道删除后 active 置空）、新增表单（17 家预设联动填充、🔍 按密钥检测厂商、📡 拉取上游模型、extraBody JSON）
3. **账号管理**（弹窗）：注册（邮箱/密码/昵称/套餐/有效期）、用户列表（套餐/用量/最近登录）、编辑、重置密码（吊销全部会话）、删除
4. **维护**：开机自启（HKCU Run 键 `PaperPilotAccountServer`）、数据目录、项目目录、最新 xpi 安装指引
5. **托盘**：关闭窗口 = 最小化到托盘驻留；托盘右「退出程序」为唯一真正退出

### 首次使用

1. 双击 `启动PaperPilot后台.bat` → 点「启动后台」
2. 「通道管理」→ 新增通道（粘贴 Key 点 🔍 检测自动识别，或填本地网关地址）→ 设为活动
3. 「注册账号」→ 在 Zotero：设置 → PaperPilot 登录 → 免费使用官方模型
4. （可选）维护区开启「开机自启」
