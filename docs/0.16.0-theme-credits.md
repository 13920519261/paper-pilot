## 具体借鉴点

### ui-theme.js（界面主题）
- **yaobian-zotero**（MIT）：
  - CSS 变量映射契约——Zotero 7+ 界面颜色由 `--material-*`（面）/`--fill-*`（字）/`--color-accent`、`--arrowpanel-*` 等（强调/弹窗）驱动，覆盖这批变量即可整窗换肤；
  - `<style>` 注入在窗口 author 级、`!important` + 文档顺序取胜，作用域收在 `#main-window` 不污染 reader 子文档；
  - `Services.wm.getEnumerator` 枚举全部 chrome 窗口（`Zotero.getMainWindows()` 拿不到设置窗口）；设置窗口会被 Zotero 自行 reload，需 load 事件重挂；
  - 选中行（`.selected`）是自绘中性灰、不吃变量，必须单独覆盖；
  - "核心色板角色 + 派生角色（tab/ink2/ink3 由基色混合）"的主题数据组织。
- **zotero-night**（GPL-3.0）：Nord 色板基调（nord-night 主题配色取自 Nord 官方色板 #2E3440/#88C0D0 等，Nord 色板本身以 MIT 发布）；"UI 与阅读器一起换色"的产品形态。
- **Primer**（GitHub 设计系统，MIT）：primer-light/primer-dark 两套标准主题的色值基础。

### pdf-theme.js（PDF 阅读主题）
- **zotero-pdf-background**（无 LICENSE 文件——机制思路借鉴，代码原创重写）：
  - 核心机制洞察：Zotero 内置 pdf.js 的 `.textLayer` 覆盖在 canvas 之上且默认透明，**半透明叠色**（其默认 `opacity:0.3`）可实现"护眼底色"而完全不动 canvas 渲染；
  - `Zotero.Notifier` 监听 tab 事件 → `Zotero.Reader.getByTabID()` → `reader._iframeWindow` 定位 viewer.html iframe；
  - 阅读器工具栏中部（`.toolbar div.center`）注入切换按钮的交互；
  - `#secondary-view` 挂 MutationObserver 兼容分屏视图。
- **zotero-night**（GPL-3.0）：夜间模式 = `filter: invert(1) hue-rotate(180deg)` 反色 canvas（黑纸白字、色相保持），pdf.js 社区标准做法；viewer 底色同步加深。

### 动漫系列主题配色
原创配色（意境命名，规避商标）：樱花前线（浅粉）、薄荷苏打（浅绿）、紫罗兰夜（深紫）、苍蓝晨风（深蓝）。色彩意象参考日系动漫常见配色语言，未使用任何受版权保护的角色设计或官方色值。
