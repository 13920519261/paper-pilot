## 安装

1. 到 [Releases](../../releases) 下载最新 `paper-pilot-x.y.z.xpi`
2. Zotero → 工具 → 插件 → 右上角齿轮 → **Install Plugin From File**，选择 xpi
3. 重启 Zotero，打开 **编辑 → 设置 → PaperPilot** 填写 API Key

## AI 配置（0.14.0：账号 + 模型通道）

**方式一：登录账号（推荐，零配置）**——设置 → PaperPilot 登录后即可**免费使用官方默认模型**（连接官方服务器 `https://pp.xinglintools.top`，没有账号点「注册账号」自助注册）；账号卡片可查看套餐与每日用量、切换官方模型，登录状态本地持久化，过期自动提醒。官方服务由 PaperPilot 统一提供，不开放自建后台。

**方式二：自己的接口**——「AI 模型通道」支持注册多套 OpenAI 兼容配置（`/v1/chat/completions`）：

- 17 家厂商预设（DeepSeek / 通义 / Kimi / 智谱 / 豆包 / 硅基流动 / Ollama 本地……），粘贴 API Key 点「🔍 检测」自动识别厂商并拉取模型
- 通道可新增 / 编辑（Key 留空保持不变）/ 删除 / **实测**（真实调用返回延迟与应答）/ 一键切换；extraBody 附加参数、超时、模型列表 chips 管理
- 工具菜单与工作台内均可快速切换活动通道；旧版单通道配置与快照首次启动自动迁移为通道

设置中不预置任何密钥——请登录账号或填自己的 Key。

## 账号后台与启动管理器（0.14.0，0.14.1 增强）

仓库自带一套零依赖 Node 账号后台（`server/`），实现插件全部账号契约：注册/登录/会话/用量 + 官方模型网关（把登录用户请求转发到活动通道上游，`auto` 模型自动映射、SSE 流式透传）。

**双击项目根目录 `启动PaperPilot后台.bat`** 打开图形控制台（WinForms，对标心血管药物学习平台启动管理器）：

- **账号后台控制**：启动 / 停止 / 重启 / 查看日志 + 状态灯（端口 8000 健康检测）；可设开机自启
- **AI 模型通道管理**：通道列表 / 新增 / 编辑 / 删除 / 设为活动 / 实测 / 🔍 按密钥检测厂商 / 📡 拉取上游模型（17 家预设联动填充）——决定官方网关走哪个上游
- **官方默认模型（0.14.1）**：通道管理里一行搞定——📡 拉取活动通道模型列表 → 下拉选择（或输入自定义名）→ 设为默认，登录用户的 `auto` 即时走此模型；插件设置中的模型 chips 同样点击即选
- **账号管理**：注册账号 / 用户列表 / 改套餐与有效期 / 重置密码（吊销全部会话）/ 删除
- 关闭窗口 = 最小化到托盘驻留；也可在浏览器打开 `http://127.0.0.1:8000/admin` 网页版管理
- **公网部署（多设备/公开服务）**：经 Cloudflare Tunnel 接入自有域名（现网 `https://pp.xinglintools.top`），任何人可自助注册登录；管理面仍仅限服务器本机。步骤见 `docs/账号系统与模型通道.md`

首次使用：启动后台 → 通道管理新增一条上游并设为活动 → 注册账号 → Zotero 设置里登录即可。详见 `docs/账号系统与模型通道.md`。

## 更新通道

插件内置 `update_url`（0.14.4 起 = Gitee raw 直链），新版 push 后 Zotero 自动提示更新（无需手动重装，`git push origin main` 即发版）。
更新清单：`paperpilot-update.json`（版本条目 + Gitee raw xpi 直链）。
> 0.14.3 及更早版本的 `update_url` 指向 gujinbencao 服务器——存量用户需将仓库 `paperpilot-update.json` 上传一次到该服务器对应路径，即可收到 0.14.4 并永久切换到 Gitee 链路。

## 版本迭代流程

1. 改代码 → `manifest.json` 版本号 +1
2. 打包：`python` 把 `paper-pilot/` 打成 `paper-pilot-<版本>.xpi`（zip，源码目录内容置于根）
3. `paperpilot-update.json` 追加新版本条目
4. 提交并打 tag：`git tag v<版本> && git push origin master --tags`
5. GitHub/Gitee Releases 上传 xpi 附件

## 隐私

- 登录令牌保存在本机 Zotero 数据目录（`paperpilot-account.json`，仅本地读写），密码只在登录请求中出现、绝不落盘；卸载插件即清除
- 所有 AI 请求只发往你登录的官方网关或自己配置的服务商/本地网关，插件无任何遥测与回传
- 「真假文献识别」「被引量」等只访问 Semantic Scholar / easyScholar / Unpaywall 公开 API
